# Ecommerce store

Modern premium ecommerce frontend for electronic products.

## Stack

- Next.js App Router
- React JavaScript
- Tailwind CSS
- Zustand cart state
- React Quill editor UI for admin descriptions

## Run

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Pages

- `/`
- `/categories`
- `/category/[name]`
- `/product/[id]`
- `/cart`
- `/login`
- `/signup`
- `/admin`
- `/about`
- `/privacy`
- `/contact`
